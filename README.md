# 蝉蜕（Chrysalis）

macOS 上的本地视频转码工具：拖入视频，批量转码为 H.264 / HEVC / ProRes，默认走 Apple 硬件媒体引擎（VideoToolbox），速度优先、CPU 占用低；可选从 TMDB 获取电影元数据，人工确认后写入 MP4/MOV 容器。纯 Swift + SwiftUI，零第三方依赖。

> 「蝉蜕」取意「金蝉脱壳」——转码即蜕变：旧壳（容器）留在身后，影像本体无损，飞向新形。英文名「Chrysalis」是蛹壳——蜕变发生的静默容器；原文件保留、输出原子落盘，正合其意。

## 软件特色

- **快，且省电**：默认强制 VideoToolbox 硬件编码，M1 Pro 实测 1080p H.264 → H.264 **6.2x**、4K HEVC → 1080p H.264 **5.7x**；硬件不可用时任务明确失败，**绝不静默回退软件**。
- **纯 Apple 技术栈，零第三方依赖**：Swift 6（严格并发）+ SwiftUI + AVFoundation，不引入 FFmpeg / libav。
- **本地优先、安全落盘**：所有转码在本机完成，不联网上传（仅电影元数据匹配访问 TMDB）；输出原子落盘，失败/取消不留半个文件；沙盒 + 安全书签。
- **批量队列**：多文件串行执行、单任务取消/重试、一键清除已结束；缩略图、实时进度、速度与剩余时间；重启自动恢复队列，中断任务可重试。
- **5 个内置预设 + 可视化编辑器**：兼容优先 / 均衡 / 小体积 / 高质量 / 剪辑用 ProRes；自定义分辨率、帧率、容器、音频，码率实时体积估算。
- **码率精细控制**：平均码率 / 质量优先 / 目标大小（MB）三选一；关键帧间隔、H.264 Profile、ProRes 422 全家族 + PCM 16/24-bit。
- **电影元数据（可选 TMDB）**：自动匹配片名/年份/导演/海报 → **人工确认后才转码**（永不静默写入）；元数据与海报写入 MP4/MOV 容器，Finder「显示简介」直接可看；支持本地代理。
- **历史记录**：每次转码自动留存（上限 500 条），随时 Finder 定位输出、一键重新转码、编辑元数据；转码完成/失败系统通知（可关）。
- **极简克制的界面**：暗色优先、单一强调色、等宽数字；完整支持 Reduce Motion；全中文界面。

## 系统要求

- macOS 27.0 或更高版本
- 需要 Apple 硬件编码器（Apple Silicon 或含 Apple T2 及以上媒体引擎的 Mac）；应用启动时会自动检测并在界面展示硬件能力矩阵

## 从源码构建

```bash
git clone git@github.com:Darkiiiiiice/Chrysalis.git
open Chrysalis/Chrysalis.xcodeproj
# Xcode 中直接 ⌘R 运行；或命令行：
xcodebuild -project Chrysalis/Chrysalis.xcodeproj -scheme Chrysalis -configuration Debug build
```

## 使用方法

### 基本流程

1. **添加文件**：把 MP4 / MOV / M4V 视频拖进窗口，或 `⌘O` 选择文件（不支持的类型会自动过滤并提示）。
2. **选预设**：在添加面板中选择一个预设；也可以在「预设」页把某个预设设为默认，之后新任务自动使用。
3. **选输出文件夹**：点击底栏「选择输出文件夹」或 `⇧⌘O`；重名文件自动加 `-1` 后缀，绝不覆盖。
4. **开始**：点击「开始」或 `⌘↩`。任务串行执行，行内可看进度、倍速与剩余时间；单个任务可随时取消（`⌘.` 取消全部）。
5. **失败重试**：取消/失败/中断的任务点行尾 ↻ 重试；已结束任务可从行内垃圾桶按钮或右键移除，「清除已结束」一键清理。

### 转码电影（可选）

1. 在「设置」页填入 TMDB API Key（v3）或 Read Access Token（v4）→「验证并保存」。凭据只存系统钥匙串；国内网络可在「网络代理」分组配置代理（如 Clash 默认 `127.0.0.1:7890`）→「测试连接」。
2. 添加文件时勾选「这些是电影」（或在检查器中对单个任务打开「标记为电影」）。
3. 应用自动解析文件名并从 TMDB 匹配候选；队列行直接显示匹配结果（如 `电影 · 已匹配《大护法》（2017）（待确认）`）。
4. 点击「确认元数据…」打开确认窗口：左侧候选列表（海报/标题/年份/简介），右侧可编辑表单；也可以不联网、纯手动填写。
5. **确认之前任务不会开始**——自动匹配永远不会静默写入。确认后转码，标题/导演/简介/海报写入输出容器（MP4 用 iTunes 字段、MOV 用 QuickTime 字段），Finder「显示简介」即可查看。

### 预设

- 内置 5 个预设只读：兼容优先（H.264）、均衡（HEVC）、小体积（H.264）、高质量（HEVC）、剪辑用 ProRes（ProRes 422 + MOV + PCM）；「复制为自定义」即可创建自己的预设（如截图中的「超高质量」HEVC 4K）。
- 「复制为自定义」后可编辑：分辨率（保持源 / 2160p ~ 480p，只缩不放）、帧率（只降不升）、容器（MP4 / MOV）、音频（最高 320 kbps、采样率、单/立体声）、码率控制（平均码率 / 质量优先 / 目标大小）、关键帧间隔与 H.264 Profile；编辑器内实时显示预计体积。

### 历史与输出

- 每个任务到达终态自动进入「历史」（最多 500 条）：右键可在 Finder 中显示输出、**重新转码**（沿用当时的预设与元数据）、编辑元数据、删除记录。
- 转码完成 / 失败会发系统通知（「设置 → 通知」可关；取消与中断不打扰）。
- 中途退出应用再打开：队列自动恢复，正在转码的任务标记为「已中断」，一键重试。

### 键盘快捷键

| 快捷键 | 功能 |
|---|---|
| `⌘O` | 添加文件 |
| `⇧⌘O` | 选择输出文件夹 |
| `⌘↩` | 开始全部 |
| `⌘.` | 取消全部 |
| `⌘I` | 显示 / 隐藏检查器 |

## 支持范围（v1）

| | |
|---|---|
| 输入格式 | MP4、MOV、M4V |
| 输出格式 | H.264、HEVC（MP4 / MOV）、ProRes 422 系列（MOV） |
| 分辨率 | 保持源或缩放至 2160p / 1440p / 1080p / 720p / 480p（只缩不放） |
| 不支持 | MKV / AVI / WebM 等容器输入；AV1 / VP9 编码；HDR 片源（检测后拒绝）；字幕烧录、多音轨选择、剪辑 |

## 技术实现

- 纯 Swift 6 + SwiftUI + 系统框架（AVFoundation / VideoToolbox / CoreMedia / CoreImage），**零第三方依赖**。
- macOS 27 新 AVFoundation 异步模型：`AVAssetReader` 解封装解码 + VideoToolbox 硬件编码 + `AVAssetWriter` 封装；旋转/缩放走 `AVVideoComposition` 合成。
- 电影元数据只在勾选「电影」时联网（TMDB）；凭据存 Keychain，搜索/详情/海报本地缓存 7 天；请求串行 + 限速，401 / 429 / 超时均有中文错误提示。
- App Sandbox + Hardened Runtime；文件访问全部走安全书签；队列、历史、预设为本地 JSON，绝不改动源文件。
