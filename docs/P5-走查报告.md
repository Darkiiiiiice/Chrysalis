### 2.3 发现并修复：全局强调色丢失（重要）

**现象**：实机窗口里侧边栏选中态是 **macOS 系统蓝**，与「只允许一个强调色」（§8.2）冲突。

**根因**：`Theme.swift` 的注释写明「强调色复用系统 `AccentColor` 槽位……同时让系统控件自动取色」，但工程**没有设置** `ASSETCATALOG_COMPILER_GLOBAL_ACCENT_COLOR_NAME`——`AccentColor` 资产从未成为 App 的全局强调色。于是：

- SwiftUI 控件（按钮、开关）靠 `.tint(Theme.accent)` 取到青色 ✅
- 系统绘制的部分（侧边栏 `List` 选中态、焦点环）仍走系统蓝 ❌

**修复**：Debug / Release 两个配置各加一行 `ASSETCATALOG_COMPILER_GLOBAL_ACCENT_COLOR_NAME = AccentColor`。

**验证**：真实窗口截图确认选中态由系统蓝变为资产青色 `#5BE1FF`（暗色）/ `#007C91`（浅色）。

### 2.4 空状态与 Toast

- **空状态**：队列无任务时为拖放区（1px 虚线、圆角 16、24px 细网格 5% 透明度），文案「拖入视频 / 或点击选择文件」，点击进入文件选择；`accessibilityLabel` 合并为一句。
- **Toast（此前缺失，按 §8.4 补齐）**：
  - 位置：窗口底部居中；`surfaceElevated` + 1px border + 阴影 `0 8 24 rgba(0,0,0,0.35)`；圆角 10。
  - 4 秒自动消失，可手动关闭；可带一个次级动作。
  - **分流**：错误 → 队列顶部 inline banner（不自动消失）；非错误 → 底部 Toast。
  - 批量结束示例：「已完成 N 个任务」+「在 Finder 中显示」。
  - 文案宽度自适应：短文案贴合内容，超过 340pt 两行内换行，不把浮层撑得过宽。

### 2.5 页面核对

队列 / 预设 / 历史 / 设置 四页在暗色与浅色下均逐页截图核对：间距为 4pt 网格、字号取自 §8.2 字体表、数字用等宽、单一强调色、无霓虹/玻璃/粒子/满屏卡片、列表行无圆角无阴影。

## 4. 空状态 / 错误状态 / 键盘导航 / VoiceOver

- **错误状态**：顶部 inline banner（左侧 2px 竖线、详情可选中复制），不弹大 alert；任务行失败态在第二行显示人话原因，检查器「错误」分区有完整文本与「复制详情」。
- **键盘导航**：主流程快捷键 ⌘O（添加）/ ⇧⌘O（输出目录）/ ⌘↩（开始）/ ⌘.（取消）/ ⌘I（检查器）已覆盖；**新增**任务行 `.focusable(true)`，Tab 可聚焦到任务行、回车打开检查器；行内图标按钮均带 tooltip + `accessibilityLabel`。
- **VoiceOver**：**新增**任务行摘要（文件名 + 预设 + 状态 + 进度 + 速度 + 剩余时间 + 失败原因 + 电影元数据状态）；缩略图、预设标签对 VoiceOver 隐藏（纯装饰），状态点不再被读成空白元素。

## 5. 遗留与建议

1. **浅色模式未做全流程实机走查**：本轮只核对了 4 个主页面截图，转码中、Sheet、拖放态等浅色表现留待下次实机走查。
2. **浅色分隔线对比度 1.15:1**：为 §8.2 指定值，不影响文字可读性；若日后想更清晰可把浅色 `border` 调到 `#D9DEE6`。
3. **任务行右键菜单无键盘等价**：菜单项（确认元数据 / 重试 / 取消 / 移除）目前只能右键访问；回车打开检查器是部分替代，后续可把行内按钮纳入 Tab 顺序。
4. **截图辅助的材质盲区**：`--capture` 不合成系统材质层，侧边栏会渲染成黑色；取证请用真实窗口截图。
5. **README 截图待重拍**：`docs/screenshots/*.png` 是强调色修复**之前**拍的，侧边栏选中态仍是系统蓝；其中 `movie*.png` 依赖 TMDB 与确认 Sheet 交互、无法用现有截图辅助自动复现，故本轮未改。下次全量重拍 README 截图时一并更新。
